- **STARLINK**: WORST-CASE (max) convention. peak_gain_dbi: SpaceX Gen2 Ku-band maximum antenna gain 44 dBi, FCC-22-91A1 (2022) para. 42. eirp_density_dbw_per_mhz: UNIT-CORRECTED from FCC-22-91A1 para. 42. The order prints "maximum EIRP density between -11.9 dBw/MHz and -8.3 dBw/MHz", but 47 CFR Part 25 specifies Ku-band (below 15 GHz) EIRP density per 4 kHz, and -8.3 is a PER-4-kHz EIRP: SpaceX's 2016 Ku technical attachment (SAT-LOA-20161115-00118) tabulates the Ku user-downlink maximum as -11.07 dBW/4kHz = 12.91 dBW/MHz, and Del Portillo et al. (2019, Table 3) report +12.7 dBW/MHz for Starlink. Converting the top of the filed range: -8.3 dBW/4kHz + 10log10(250) = +15.68 dBW/MHz; the range -11.9..-8.3 dBW/4kHz is +12.1..+15.7 dBW/MHz. beamwidth_deg: DERIVED from the 44 dBi peak via HPBW ~ 70*lambda/D (aperture efficiency 0.6, ASSUMED); no filing states the satellite beamwidth. freq_ghz: centre of the Ku-band user downlink 10.7-12.7 GHz. bandwidth_mhz: Starlink Ku channel, emission designator 240MD7W (SpaceX FCC filings). system_noise_temp_k: ASSUMED terminal value. beam_steering: PFD-CONSTANT is the primary Starlink Ku model. SpaceX "adjusts power to maintain a constant PFD on the surface of the Earth" as the beam steers (FCC-22-91A1 para. 42); the 10.7-11.7 GHz Ku operations are authorized up to the section 25.208(b) PFD limits (FCC-22-91A1 para. 43; 47 CFR 25.208(b): -140 dBW/m^2 per 4 kHz, or -116 dBW/m^2 per 1 MHz, for 25-90 deg). pfd_anchor_elevation_deg: 25 deg, the Starlink Ku minimum service elevation below 62 deg N latitude (FCC-22-91A1 para. 42/45; 5 deg at/above 62 deg N). The EIRP_max at this edge fixes PFD_const = EIRP_max - 10log10(4 pi r_max^2), so EIRP density grows as 10log10(4 pi r^2) with slant range r and the received interference is range-independent.
- **KUIPER**: beam_steering: constant-EIRP, ASSUMED (no Kuiper filing in our record states PFD-constant power control, and the Kuiper Ka-band user downlink does not overlap the Starlink/OneWeb Ku co-frequency pair). peak_gain_dbi / beamwidth_deg / freq_ghz: Kuiper experimental STA satellite user beam 35 dBi, 2.8 deg 3-dB spot beam at 19.8 GHz, apps.fcc.gov/els/GetAtt.html?id=347260 (19.6-20.1 GHz). eirp_density_dbw_per_mhz: ASSUMED (the STA gives total EIRP 36 dBW, not a per-MHz density). Ka-band (19.8 GHz) is above the 15 GHz threshold below which 47 CFR Part 25 states EIRP density per 4 kHz, so the 4-kHz unit conversion does not apply here. bandwidth_mhz: largest Kuiper emission designator 500MG7W (FCC). system_noise_temp_k: ASSUMED.
- **ONEWEB**: beam_steering: constant-EIRP, ASSUMED. The Starlink-specific PFD-constant power control (FCC-22-91A1 para. 42) has no cited OneWeb equivalent in our record, so ONEWEB-as-interferer keeps constant EIRP. peak_gain_dbi / beamwidth_deg: ASSUMED (OneWeb user-beam values; no citable per-beam value, FCC-17-77 only references binary Ku/Ka antenna-gain mask files). eirp_density_dbw_per_mhz: Del Portillo et al. 2019 (Acta Astronautica 159, Table 3, p. 5): OneWeb user-beam downlink 34.6 dBW per beam over 250 MHz = +10.6 dBW/MHz. After the Starlink Ku unit correction the model's Starlink per-beam EIRP (15.68 dBW/MHz over 240 MHz = 39.5 dBW) agrees with Del Portillo's 36.7 dBW within ~3 dB, so the same source is a consistent public reference for both systems. The earlier C/N-target value (+0.2 dBW/MHz, scripts/calibrate_oneweb_eirp.py) is retained only as a sensitivity row, not as a design rule. freq_ghz: centre of the Ku-band user downlink 10.7-12.7 GHz. bandwidth_mhz: OneWeb Ku channel (emission designator 125MG7W). system_noise_temp_k: ASSUMED terminal value.

## (d) PFD-constant (primary) vs constant-EIRP (sensitivity)

Same run family, only the interferer beam-steering model differs (`--steering constant_eirp` versus the per-beam config default in which Starlink is PFD-constant).  Under PFD-constant the interferer stops gaining power once it is nearer than the 25 deg service edge, so its aggregate interference is range-capped; constant-EIRP holds the maximum density at all ranges, an upper bound.
